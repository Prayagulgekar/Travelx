# PDF fonts

Embedded (subset) into generated PDFs so customer names, addresses and amounts render correctly.

| File | Coverage | Licence |
|---|---|---|
| DejaVuSans.ttf, DejaVuSans-Bold.ttf (v2.37) | Latin incl. extended and Vietnamese, Greek, Cyrillic, ₹ € £ and common symbols | DejaVu / Bitstream Vera licence (free to redistribute), see LICENSE-DejaVu.txt |
| NotoSansDevanagari-Regular.ttf, NotoSansDevanagari-Bold.ttf | Devanagari (Hindi, Marathi, Nepali), used as a per-character fallback | SIL Open Font License 1.1, see LICENSE-NotoSansDevanagari-OFL.txt |

Characters covered by neither font are printed as "?".
